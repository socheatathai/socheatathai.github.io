## Keep content close to the code

MDX combines Markdown with React components. Articles live in `src/content/blog/YYYY/month/` as `.mdx` files, grouped by publication year and a lowercase month abbreviation. For example, this article lives in `src/content/blog/2026/jan/example.mdx`, with its Khmer translation beside it as `example.km.mdx`.

The frontmatter at the top of the English file supplies a permanent `slug`, title, description, publication date, and tags. The `slug: "example"` value makes this article available at `/blog/example/`, even if its file moves to another folder. The Khmer file shares that slug and URL through the language switch.

## A simple publishing checklist

- Give the article a clear title and a short description.
- Use headings to organize ideas.
- Explain why each code example is useful.
- Check links and read the finished article before publishing.

To add another article, copy this file into the appropriate year and month folder, give it a new filename and a unique `slug`, update its frontmatter, then replace the example content. Add a matching `.km.mdx` file beside it for Khmer. The blog index discovers nested MDX files automatically when the site is built.
