## រក្សាមាតិកានៅក្បែរកូដ

MDX រួមបញ្ចូល Markdown ជាមួយសមាសភាគ React។ អត្ថបទជាឯកសារ `.mdx` ស្ថិតនៅក្នុង `src/content/blog/YYYY/month/` ដោយរៀបចំតាមឆ្នាំផ្សព្វផ្សាយ និងឈ្មោះខែជាអក្សរកាត់អង់គ្លេសតូច។ ឧទាហរណ៍ អត្ថបទនេះស្ថិតនៅក្នុង `src/content/blog/2026/jan/example.mdx` ហើយការបកប្រែជាភាសាខ្មែរស្ថិតនៅក្បែរគ្នាក្នុងឯកសារ `example.km.mdx`។

ទិន្នន័យនៅខាងលើឯកសារអង់គ្លេសកំណត់ `slug` អចិន្ត្រៃយ៍ ចំណងជើង សេចក្តីពិពណ៌នា កាលបរិច្ឆេទផ្សព្វផ្សាយ និងស្លាកប្រធានបទ។ តម្លៃ `slug: "example"` ធ្វើឱ្យអត្ថបទនេះអាចចូលមើលបានតាម `/blog/example/` ទោះបីជាឯកសារត្រូវបានផ្លាស់ទីទៅថតផ្សេងក៏ដោយ។ ឯកសារខ្មែរប្រើ `slug` និង URL ដូចគ្នាតាមរយៈប៊ូតុងប្តូរភាសា។

## បញ្ចូលឧទាហរណ៍កូដដែលមានប្រយោជន៍

ឧទាហរណ៍ខ្លីមួយជួយឱ្យអ្នកអានមានកូដជាក់ស្តែងសម្រាប់សាកល្បង៖

```tsx
type GreetingProps = {
  name: string;
};

export function Greeting({ name }: GreetingProps) {
  return <p>Hello, {name}!</p>;
}
```

ប៊ូតុងចម្លងនៅខាងលើអាចចម្លងកូដនេះទៅក្តារតម្បៀតខ្ទាស់របស់អ្នក។
