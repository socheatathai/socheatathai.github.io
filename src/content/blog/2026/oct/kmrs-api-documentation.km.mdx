## មុខងាររបស់គម្រោង

### ឯកសារ API អន្តរកម្ម

ស្វែងយល់ពីឯកសារ API អន្តរកម្មរបស់ KMRS Tech នៅក្នុងកន្លែងតែមួយ។

### ស្វែងយល់ និងសាកល្បង API

ស្វែងយល់ និងសាកល្បង API endpoints តាមរយៈឯកសារ Swagger។

### ការភ្ជាប់ផ្នែកខាងមុខ

ឯកសារ API ច្បាស់លាស់ជួយអ្នកអភិវឌ្ឍភ្ជាប់កម្មវិធីផ្នែកខាងមុខ។
